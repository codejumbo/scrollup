# Scrollup Documentation Skill

This file describes the documentation available in this Scrollup site.
Use it to understand the structure and content of the docs.

## API reference

- **CLI** (/api-reference/cli): Command-line interface reference for development, building, and content management.
- **Config options** (/api-reference/config-options): Complete reference for all configuration options available in Scrollup.

## Authoring

- **Built-in components** (/authoring/built-in-components): Scrollup includes 8 MDX components for callouts, badges, steps, tabs, link grids, and API endpoints. Import and use them directly in your content.
- **Code blocks** (/authoring/code-blocks): Syntax highlighting, filenames, line highlights, and copy buttons — all built in.
- **Frontmatter schema** (/authoring/frontmatter-schema): Every MDX page requires frontmatter metadata. Learn the required and optional fields that control how your page appears in navigation and search.
- **Link grids** (/authoring/link-grids): Guide readers to related pages with clean, navigational card grids.
- **Markdown & MDX** (/authoring/markdown-and-mdx): Write documentation in Markdown with the power of JSX components when you need them.
- **Notes & asides** (/authoring/notes-and-asides): Use callouts to highlight important information without disrupting the reading flow.
- **Tabs** (/authoring/tabs): Organize alternative content — like package manager commands or platform-specific instructions — into clean tabbed panels.

## Deployment

- **Cloudflare Pages** (/deployment/cloudflare-pages): Deploy your Scrollup site to Cloudflare Pages for fast, globally distributed hosting.
- **GitHub Pages** (/deployment/github-pages): Deploy your Scrollup site to GitHub Pages using GitHub Actions for free static hosting.
- **GitLab Pages** (/deployment/gitlab-pages): Deploy your Scrollup site to GitLab Pages using GitLab CI/CD pipelines.
- **Netlify** (/deployment/netlify): Deploy your Scrollup site to Netlify with continuous deployment and instant rollbacks.
- **Self-Hosted** (/deployment/self-hosted): Deploy your Scrollup site to your own server using Nginx or Apache.
- **Static hosting** (/deployment/static-hosting): Deploy your Scrollup documentation site to any static hosting provider. Build once, host anywhere.
- **Vercel** (/deployment/vercel): Deploy your Scrollup site to Vercel with automatic preview deploys for every branch.

## Getting started

- **Configuration** (/getting-started/configuration): All the options available in your Scrollup configuration file, from site metadata to theme customization.
- **Installation** (/getting-started/installation): Get a documentation site running in under five minutes. You need Node.js 20 or later and a terminal.
- **Introduction** (/getting-started/introduction): Scrollup is a documentation platform built for clarity, beauty, and speed. Learn what makes it different.
- **Project structure** (/getting-started/project-structure): How files and folders in a Scrollup project map to pages, navigation, and configuration.

## Theming

- **Colors & typography** (/theming/colors-and-typography): The design system behind Scrollup — warm backgrounds, editorial typefaces, and a carefully calibrated color palette.
- **Custom CSS** (/theming/custom-css): How to extend and override Scrollup's styles while maintaining design consistency.
- **Dark mode** (/theming/dark-mode): A hand-picked dark theme that respects your system preference and stays comfortable for long reading sessions.
- **Layout & navigation** (/theming/layout-and-navigation): Understand the three-column grid layout, responsive breakpoints, and how sidebar navigation is built from your content.
